# SeekSense website

The website for SeekSense: talking therapy, mental health assessment and help finding the right support.

Statically generated pages (TypeScript, run directly by Node 22) with a small, dependency-free Node server for the enquiry form.

```bash
npm install
npm run dev            # preview with highlighted placeholders at http://localhost:4321
npm run check          # typecheck, lint, unit and integration tests
npm run test:browser   # Playwright checks (layout, keyboard, menu, form)
npm run launch-check   # lists every fact still awaiting confirmation
```

- `src/config/site.ts`: business facts and urgent help numbers. Unconfirmed facts are `pending(...)`.
- `src/content/services/*.md`, `src/content/articles/*.md`: editorial content. See `docs/EDITORIAL-GUIDE.md`.
- `src/pages/`: page templates. `src/components/`: layout and shared parts. `src/styles/main.css`: the design system.
- `server/`: enquiry validation, the mailer boundary, security headers and the server.

Start with **docs/HANDOVER.md**. Deployment: **docs/DEPLOY-CLOUDFLARE.md**. Also see `docs/AUDIT.md`, `docs/REGULATORY-NOTES.md` and `docs/DESIGN-SYSTEM.md`.

Fonts: Newsreader and Hanken Grotesk, under the SIL Open Font Licence (`public/fonts/*-OFL.txt`). Artwork is generated by `scripts/generate-art.mjs`.
